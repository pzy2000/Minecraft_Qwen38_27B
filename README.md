# 星海方舟 Starbound Voxel

**语言：** [中文](README.md) · [English](README.en.md)

一个用纯 HTML5 + JavaScript + Three.js 实现的“无人深空 × 体素生存”像素游戏。
一颗宇宙种子会递归派生**无限银河 × 无限恒星系**：每个恒星系稳定生成 2–6 颗不同类型的行星和 1 座轨道空间站；玩家可以采集、建造，寻找随机传送门，驾驶飞船使用跃迁引擎在星系内航行，或消耗曲速电池向任意方向的邻近恒星系跳跃。零运行时依赖、零构建 —— **双击 `index.html` 即可在浏览器中游玩**。

## 星际探索核心

- **无限宇宙**：宇宙种子 → 银河 → 恒星系 → 行星 四级确定性派生；恒星系按整数坐标 (g, s) 向任意方向无限展开，名称、恒星光谱分类（O–M）、行星数（2–6）与类型布局全部由种子决定。旧存档自动迁移为「起源恒星系」且地形逐位不变。
- **银河星图**：星图新增「银河」标签页——5×5 视窗浏览邻近恒星系（◀▲▼▶ 无限平移），显示已探索/未知状态、距离与曲速电池成本；点击锁定航线、点火即启动跨系曲速。
- **种子星系**：每个恒星系内确定性生成繁茂、荒漠、冰封、剧毒、熔火、海洋等 2–6 颗行星 + 1 座空间站；每颗天体拥有独立地形种子、环境色、坐标与世界进度。
- **跨系跃迁经济**：跨恒星系跳跃消耗**曲速电池**（任意两枚高阶晶体 + 铁锭合成，产物自动装填飞船）——各星球专属晶体从此有了战略用途；系内跃迁仍用普通燃料，抵达空间站自动补满。
- **随机传送门**：每颗行星稳定生成 3–4 扇传送门，目的地由种子决定，至少一扇连接空间站；穿门免费且不会消耗跃迁能量。
- **透明座舱、行星飞行与跃迁引擎**：靠近飞船按 `E` 进入真实透明座舱，可透过舱窗观察持续变化的昼夜、云雨、雷电、Mob 与世界。生命维持会把累计有害暴露净化到 `0%` 并隔绝雷击/Mob攻击；鼠标转向、`W/S` 推进制动、`A/D` 侧滚辅助转弯、`Space/Shift` 升降，辅助防撞并支持软着陆。飞行中长按 `E` 启动着陆辅助：高度低于地面 24m 时自动搜索平整干燥地点并完成降落（HUD 显示 `AUTO LAND`），落地后轻按 `E` 离舰。座舱内按 `H` 打开星图跃迁，跨天体仍沿用 verified-save 航行事务。
- **轨道空间站**：独立的真空体素平台、航行终端、门户网络与像素星空；抵达后自动补满跃迁能量。
- **多世界持久化**：v6 存档按「恒星系地址 × 天体」隔离方块修改、箱子/熔炉、落点与时间，共享背包、生命、饥饿、飞船、曲速电池与发现记录；只持久化有玩家痕迹的世界（其余随时从种子再生），其他恒星系档案按 LRU 裁剪；旧 v5/v4 存档自动迁移且进度无损。
- **双端界面**：移动端靠近飞船时右上入口会从“星图”切换为“登舰”，舱窗拖动转向，并提供推进、制动、升、降、星图和离舰按钮。透明座舱 HUD 在桌面、竖屏、低高度横屏和 200% 等效极窄视口下均保留中央世界视野并支持 reduced-motion。

## 成长系统：新手教程 · 成就 · 星海图鉴

- **新手教程**：新世界落地后左上角出现分步任务卡，沿「移动 → 采原木 → 木板 → 工作台 → 木镐 → 挖石 → 熔炉 → 烧铁 → 登舰启程」的 11 步链引导；每步自动检测完成并解锁下一步，可随时「跳过教程」，也能在暂停菜单「教程回顾」重新开启。
- **成就系统**：52 项成就分属 生存 / 建造 / 探索 / 收集 / 挑战 / 隐藏 六大类，支持进度型成就（如「掘地三千尺：挖掘 1000 方块 472/1000」）与 3 个隐藏彩蛋；解锁时金框弹窗 + toast 提示，`J` 键打开面板查看总完成度与分类统计。成就随当前存档保存。
- **星海图鉴**：`B` 键打开四页签收集册——「物品图鉴」82 条按 工具/食物/材料/功能方块/矿石晶体/植物/自然方块 分组，未获得显示像素剪影；「生物」6 种图鉴带程序化像素立绘、栖息地与习性；「群系」22 种踏入即点亮（以地表方块配色渲染环境卡）；「星域档案」展示已抵达天体的星体色卡、类型与所属恒星系统计。获得物品、靠近生物、踏入群系、抵达天体都会自动编录。

## 运行

```bash
# 方式一：直接双击 index.html（推荐）
open index.html

# 方式二：本地服务器（可选）
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

> 需要支持 WebGL 的浏览器（Chrome / Edge / Firefox / Safari）。
> 存档使用 localStorage；若浏览器对 file:// 协议限制存储，请用方式二运行。

背包、工作台、熔炉、箱子、合成手册和设置右上角均有固定可见的关闭按钮；低高度横屏时面板会改用横向布局，仍放不下的内容在面板内部滚动。设置中可调「触摸灵敏度」与「渲染分辨率」（低配设备可降到 0.35×）。竖屏时会提示旋转至横屏（可选择继续）。桌面浏览器不受影响。

### 性能设置与预设

设置面板提供完整性能调节，所有选项即时生效并自动保存：

| 选项 | 说明 |
|---|---|
| **性能预设** | 「流畅」（30fps·低分辨率·少粒子雨滴生物·关阴影）/「均衡」/「高画质」三键一键切换 |
| 帧率上限 | 原生 / 30 / 60 fps——高刷新率屏幕（如 120Hz）建议限 60，显著降热降耗 |
| 渲染分辨率 | 0.35×–1×，低配设备最有效的流畅度开关 |
| 粒子 / 雨滴 / 生物密度 | 按比例缩减特效与生态规模 |
| **实时阴影** | 树叶实时投影（关/中/高）：影子随太阳方位全天扫动、随风摇曳，雨天自动减弱，洞穴/树冠正下方不叠加；触屏默认关 |
| **树叶风摇** | 树叶顶点风摆强度滑杆（雷暴风力增强）；系统开启「减少动态效果」时自动停用 |

触屏设备首次游玩自动套用「均衡」档（60fps · 分辨率 0.8× · 特效 0.7）；老玩家已保存的设置不受影响。渲染层优化：生物合批为单次绘制、雨滴单批次实时裁剪、帧缓冲按需保留、树叶阴影深度 pass 仅渲染树叶组（正交深度图 + PCF 软采样）。

## 设置

主菜单或暂停菜单点"设置"：鼠标灵敏度、音量、视场角 (FOV)、雾距四项滑杆，即时生效并自动保存在本浏览器（localStorage）。

### 游戏难度

设置面板可切换四种难度（默认「困难」），切换立即生效并自动保存：

| 难度 | 说明 |
|---|---|
| **和平** | 不生成僵尸等敌对生物（切换时立即清空场上怪物）、饱食度不下降也不会饿死 |
| **简单** | 僵尸伤害 ×0.7、移动略慢；饥饿最多扣到 10 血，不会饿死 |
| **困难** | 标准规则：僵尸伤害 3；饥饿可扣至 1 血 |
| **噩梦** | 僵尸伤害 ×2、速度 +18%、数量 ×1.5；**死亡无法复活**——死亡瞬间删除该世界存档，只能回到主菜单重新开始 |

## 游戏内容

- **无限程序化行星**：行星在 X/Z 方向按玩家位置持续流式生成区块，穿过旧 `0..255` 范围或进入负坐标都不会再遇到基岩墙/虚空；远处区块会卸载以限制内存，玩家 edits 与容器元数据永久保留。旧存档的 256×256 legacy core 仍逐坐标原样生成；空间站继续保持有限真空平台。地形使用 64 位种子 + Improved Perlin、样条塑造、3D 密度场、意面隧道/奶酪空腔与煤铁矿脉
- **二十二种生物群系**：MultiNoise 五维气候参数空间最近邻选择（温度/湿度/大陆性/侵蚀度/奇异性）——海洋、海滩、石岸、平原、森林、白桦森林、沙漠（仙人掌/砂岩层）、丛林、稀疏丛林、热带草原（金合欢稀树）、针叶林、原始针叶林（灰化土、2×2 巨型云杉、苔石巨砾）、雪原、风袭丘陵（砾石斑块）、尖峭山峰（雪帽石峰）、冰封山峰（浮冰）、石峰、恶地（红沙顶 + 陶瓦层理条纹）、蘑菇林（菌丝体地表 + 巨型红/棕蘑菇）、沼泽（低地湿原疏林）、樱花树林（斜干粉团樱花树）、黑森林（暗叶密林 + 苔石巨砾）；山峰雪线更低，雪线之上自动覆雪
- **种子系统**：对齐 Minecraft 规则——纯数字串按 64 位 long 解析（支持负数），其他文本走 Java String.hashCode 散列，留空随机（crypto 熵源）；每个噪声实例经 splitmix64 加盐派生独立流；主菜单可输入种子
- **光照系统**：天光（随昼夜渐变，洞穴漆黑）+ 块光（火把恒亮）双通道 BFS 传播，方块增删增量重算；**平滑光照**：每个顶点对相邻 4 格光值平均插值 + 环境光遮蔽（AO），转角明暗过渡自然；火把需依托放置，照亮半径约 14 格
- **挖掘与放置**：DDA 体素射线选取，长按挖掘带进度裂纹动画；不同方块有不同硬度，镐类工具大幅加速石头系并解锁矿石等级（煤→木镐、铁→石镐）；基岩不可破坏

- **生物**：被动生物按群系出没——羊（平原/针叶林，会咩叫，击杀掉羊毛）、猪与鸡（森林/丛林/平原，掉生猪排/生鸡肉）、兔子（沙漠/雪原，跑得最快，掉生兔肉）、猫（平原/森林等温暖群系，4 种花色会喵叫，击杀掉 2 猫毛——2 猫毛可合成猫毛毡）；受击后会背向玩家加速逃跑；夜晚追击的僵尸（会呻吟，日出自燃——洞里不烧），攻击有视线与高度判定不再隔墙伤人；剑类武器伤害更高

- **第一人称手持物**：右下角实时显示手持方块（立方体）或工具（精灵），挖掘/攻击/放置带挥动动画，走路轻微摆动

## 新手流程建议

1. 砍树得橡木 → 背包 2×2 合成木板 → 2 木板合成木棍
2. 4 木板合成工作台，放置后对准按 E 打开 3×3
3. 3 木板+2 木棍合成木镐 → 长按右键开采石头与煤矿
4. 煤炭+木棍合成火把（×4），插在洞穴里照亮；8 石头合成熔炉，铁矿+煤炭烧出铁锭升级铁镐铁剑
5. 击杀羊收集羊毛，3 羊毛+3 木板合成床：夜晚睡觉跳过黑夜并记录重生点；猎猪烤猪排补充饥饿（R 进食）

## 已知限制

- 熔炉不支持烧矿石成块/食物烟熏粒子等细节；箱子无朝向（四面同贴图）
- 遗迹为纯地表结构，不写入区块 heights 缓存（雨雪粒子等按原地形高度运行）；遗迹与巨植只出现在 v2 地形行星的 legacy core 之外
- 光照为逐格平面光照 + 顶点平滑插值；火把不支持贴墙姿态
- 单进程世界（无多人联机）
- 行星 X/Z 按区块无限流送但垂直高度仍为 64 格；默认常驻工作集与雾距有界，极高速飞行到尚未生成区块时会短暂受到加载保护
- 旧 256×256 core 初次生成约 1-2 秒 + 光照初始化约 1 秒（进度条可见）；外围区块在游玩中按小预算渐进生成
- 跨恒星系跳跃目前从空间站抵达（后续版本将支持直接降落到目标行星地表）；轨道中不落盘，页面关闭后回到最后降落点
