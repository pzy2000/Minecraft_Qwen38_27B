# 星海方舟 Starbound Voxel

**语言：** [中文](README.md) · [English](README.en.md)

一个用纯 HTML5 + JavaScript + Three.js 实现的“无人深空 × 体素生存”像素游戏。
一个星系种子会稳定生成 6 颗不同类型的行星和 1 座轨道空间站；玩家可以采集、建造，寻找随机传送门，驾驶飞船使用跃迁引擎探索整个星系。零运行时依赖、零构建 —— **双击 `index.html` 即可在浏览器中游玩**。

## 星际探索核心

- **种子星系**：同一星系种子确定性派生繁茂、荒漠、冰封、剧毒、熔火、海洋等行星类型；每颗天体拥有独立地形种子、环境色、坐标与世界进度。
- **随机传送门**：每颗行星稳定生成 3–4 扇传送门，目的地由种子决定，至少一扇连接空间站；穿门免费且不会消耗跃迁能量。
- **飞船避难与跃迁引擎**：降落点附近生成可交互飞船。靠近后按 `E` 真正登舰，进入密封座舱并隔绝环境危害；生命维持系统会持续把累计有害暴露净化到 `0%`，舱体也会导流雷击。座舱内可直接锁定航线并按星际距离消耗跃迁能量；`H` 保留为外部星图入口。
- **轨道空间站**：独立的真空体素平台、航行终端、门户网络与像素星空；抵达后自动补满跃迁能量。
- **多世界持久化**：v5 存档按天体隔离方块修改、箱子/熔炉、落点与时间，同时共享背包、生命、饥饿、飞船和发现记录；旧 v4 世界自动成为新星系的起始行星。
- **双端界面**：桌面端保留键鼠操作并增加 `H` 星图；靠近飞船时移动端右上入口会从“星图”切换为“登舰”。动态座舱 HUD、星图和离舰入口均适配窄屏、低高度横屏与 reduced-motion。

完整实施与验收清单见 [`docs/STARBOUND_REWORK_PLAN.md`](docs/STARBOUND_REWORK_PLAN.md)。

## 运行

```bash
# 方式一：直接双击 index.html（推荐）
open index.html

# 方式二：本地服务器（可选）
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

> 需要支持 WebGL 的浏览器（Chrome / Edge / Firefox / Safari）。
> 存档使用 localStorage；若浏览器对 file:// 协议限制存储，请用方式二运行。

## 操作说明

### 桌面（键鼠）

| 按键 | 功能 |
|---|---|
| 鼠标 | 视角（点击画面锁定鼠标） |
| WASD / 方向键 | 移动 |
| 空格 | 跳跃 / 游泳上浮 / 飞行上升 |
| Shift | 疾跑 / 飞行下降 |
| 左键 | 放置方块（使用当前快捷栏格） |
| 右键长按 | 挖掘方块（进度+裂纹动画；点生物=攻击） |
| 中键 | 吸取所看方块（优先选中已有的格） |
| 1-9 / 滚轮 | 选择快捷栏 |
| E | 靠近飞船时登舰避难 / 在座舱内离舰 · 其他位置打开/关闭背包（含 2×2 合成）· 准星对准工作台、床、熔炉或箱子时交互 |
| R | 吃掉当前快捷栏格的食物（生猪排/熟鸡肉等） |
| Q | 把当前快捷栏格的 1 个物品丢出去（掉落物可捡回） |
| F | 切换飞行模式 |
| N | 切换天气（晴 → 雨 → 雷雨循环；空间站内无效） |
| H | 靠近飞船时打开/关闭外部星图；空间站内可直接使用 |
| F3 | 显示/隐藏调试信息 |
| M | 打开/关闭合成手册（配方+烧炼一览，一键合成，长按连续合成） |
| P | 暂停菜单（手动存档 / 设置 / 快捷键速查 / 存档并回主菜单） |
| Esc | 释放鼠标 |

**背包操作**：拖拽或点击存取 · Shift+点击 整堆快搬（快捷栏↔背包；开着箱子时 快存/快取箱子）· 右键 拿半堆 / 逐个放置 · 工具不堆叠并显示耐久条。

### 移动端触控（手机 / 平板浏览器）

触屏设备自动启用，无需安装：

| 操作 | 功能 |
|---|---|
| 左半屏按住并拖动 | **浮动摇杆**移动（底座跟随落点，王者荣耀式）；推到外圈疾跑，小幅推动慢走 |
| 右半屏滑动 | 转动视角 |
| 轻点方块 | 放置手持方块 · 打开工作台/熔炉/箱子 · 床设重生点/睡觉 · 点生物=攻击 |
| 长按方块 | 持续挖掘该方块（裂纹进度照旧，可拖动手指换目标） |
| 「跳」按钮 | 跳跃 / 游泳上浮 / 飞行上升（按住生效） |
| 「降」「飞」 | 飞行模式专用：切换飞行、按住下降 |
| 右上「Ⅱ」「包」 | 暂停菜单 / 背包 |
| 右上「星图」 | 靠近飞船或位于空间站时打开星图 |
| 快捷栏 / 背包格 | 点选、拖拽、Shift/右键语义与桌面一致 |

点击开始、继续、精选世界、恢复或重生时会自动尝试进入沉浸式全屏；若浏览器拒绝，全屏失败不会阻止游玩，页面会按地址栏下方的真实可视区域自适应。退出全屏后可在暂停菜单点「进入全屏」重试。

背包、工作台、熔炉、箱子、合成手册和设置右上角均有固定可见的关闭按钮；低高度横屏时面板会改用横向布局，仍放不下的内容在面板内部滚动。设置中可调「触摸灵敏度」与「渲染分辨率」（低配设备可降到 0.35×）。竖屏时会提示旋转至横屏（可选择继续）。桌面浏览器不受影响。

### 性能设置与预设

设置面板提供完整性能调节，所有选项即时生效并自动保存：

| 选项 | 说明 |
|---|---|
| **性能预设** | 「流畅」（30fps·低分辨率·少粒子雨滴生物）/「均衡」/「高画质」三键一键切换 |
| 帧率上限 | 原生 / 30 / 60 fps——高刷新率屏幕（如 120Hz）建议限 60，显著降热降耗 |
| 渲染分辨率 | 0.35×–1×，低配设备最有效的流畅度开关 |
| 粒子 / 雨滴 / 生物密度 | 按比例缩减特效与生态规模 |

触屏设备首次游玩自动套用「均衡」档（60fps · 分辨率 0.8× · 特效 0.7）；老玩家已保存的设置不受影响。渲染层优化：生物合批为单次绘制、雨滴单批次实时裁剪、帧缓冲按需保留。

## 设置

主菜单或暂停菜单点"设置"：鼠标灵敏度、音量、视场角 (FOV)、雾距四项滑杆，即时生效并自动保存在本浏览器（localStorage）。

## 游戏内容

- **无限程序化行星**：行星在 X/Z 方向按玩家位置持续流式生成区块，穿过旧 `0..255` 范围或进入负坐标都不会再遇到基岩墙/虚空；远处区块会卸载以限制内存，玩家 edits 与容器元数据永久保留。旧存档的 256×256 legacy core 仍逐坐标原样生成；空间站继续保持有限真空平台。地形使用 64 位种子 + Improved Perlin、样条塑造、3D 密度场、意面隧道/奶酪空腔与煤铁矿脉
- **十八种生物群系**：MultiNoise 五维气候参数空间最近邻选择（温度/湿度/大陆性/侵蚀度/奇异性）——海洋、海滩、石岸、平原、森林、白桦森林、沙漠（仙人掌/砂岩层）、丛林、稀疏丛林、热带草原（金合欢稀树）、针叶林、原始针叶林（灰化土、2×2 巨型云杉、苔石巨砾）、雪原、风袭丘陵（砾石斑块）、尖峭山峰（雪帽石峰）、冰封山峰（浮冰）、石峰、恶地（红沙顶 + 陶瓦层理条纹）；山峰雪线更低，雪线之上自动覆雪
- **种子系统**：对齐 Minecraft 规则——纯数字串按 64 位 long 解析（支持负数），其他文本走 Java String.hashCode 散列，留空随机（crypto 熵源）；每个噪声实例经 splitmix64 加盐派生独立流；主菜单可输入种子
- **光照系统**：天光（随昼夜渐变，洞穴漆黑）+ 块光（火把恒亮）双通道 BFS 传播，方块增删增量重算；**平滑光照**：每个顶点对相邻 4 格光值平均插值 + 环境光遮蔽（AO），转角明暗过渡自然；火把需依托放置，照亮半径约 14 格
- **挖掘与放置**：DDA 体素射线选取，长按挖掘带进度裂纹动画；不同方块有不同硬度，镐类工具大幅加速石头系并解锁矿石等级（煤→木镐、铁→石镐）；基岩不可破坏
- **工具与武器**：木板→木棍→木镐/木剑，石/铁升级；工具有耐久（木 60 / 石 132 / 铁 251），挖矿/攻击逐步损耗并显示彩色耐久条。耐久会随 Shift、拖拽、中键、箱子、光标存档和跨星球旅行完整迁移；工具不能进入无法表达耐久的合成/炉槽
- **物品堆叠与守恒**：同类物品 ×64 自动堆叠（工具除外）；Q 键丢出物品成掉落物实体。背包已满时，容器光标余量、合成格材料、生物战利品和容器本体都会留在脚边/死亡点/原方块位置，并保留数量与工具耐久，不再静默消失
- **物理**：重力、跳跃、AABB 碰撞、游泳、飞行（创造式）；摔落伤害（高于 3 格）、水下憋气 10 秒后溺水掉血（HUD 氧气气泡）
- **昼夜循环**：30 分钟一轮，渐变天空穹顶（白天蓝→黄昏紫顶/深橙地平线→夜晚深蓝）、红橙夕阳、星空、月光；夜晚地表保留月光亮度
- **天气系统**：晴→雨→雷雨自动循环（N 键可手动切换），流动云层、雨滴、雨天压暗+近雾、闪电枝+双闪白屏+延迟雷鸣、雷击玩家伤害、雨停后白天出彩虹；雨声/雷鸣为 WebAudio 合成
- **生物**：被动生物按群系出没——羊（平原/针叶林，会咩叫，击杀掉落羊毛）、猪与鸡（森林/丛林/平原）、兔子（沙漠/雪原，跑得最快）；夜晚追击的僵尸（会呻吟，日出自燃——洞里不烧），攻击有视线与高度判定不再隔墙伤人；剑类武器伤害更高
- **生物**：被动生物按群系出没——羊（平原/针叶林，会咩叫，击杀掉羊毛）、猪与鸡（森林/丛林/平原，掉生猪排/生鸡肉）、兔子（沙漠/雪原，跑得最快，掉生兔肉）；受击后会背向玩家加速逃跑；夜晚追击的僵尸（会呻吟，日出自燃——洞里不烧），攻击有视线与高度判定不再隔墙伤人；剑类武器伤害更高
- **合成系统**：背包 2×2 合成格（橡木→×4 木板、2×2 木板→工作台、2 木板→×4 木棍）、工作台 3×3 合成格（镐/剑/床/熔炉/箱子）、合成手册（M 键查看 13 条配方+烧炼表，一键合成）；床（3 羊毛+3 木板）在工作台合成，半高可站上
- **熔炉与烧炼**：8 石头合成熔炉；铁矿石→铁锭、沙子→玻璃、三种生肉→熟肉（熟食回复更多饥饿）；燃料为煤炭（8 件）/木板/木棍/原木，火焰与烧制进度条实时显示；关面板后炉子继续烧制
- **箱子**：8 木板合成，27 格容器；存入的工具保留剩余耐久；挖掉后全部内容退回背包（放不下变成地上掉落物）
- **饥饿与进食**：10 个鸡腿的饥饿值，随疾跑/游泳/跳跃/挖掘消耗；饥饿 ≥9 才会自然回血（回血额外加速消耗）；饥饿归零缓慢掉血（降到 1 心为止）；按 R 进食，生猪排 +3 / 熟猪排 +8 等
- **床的功能**：对准床按 E 设置重生点；夜晚按 E 睡觉直接跳到清晨（渐黑过渡），僵尸白天自燃
- **战斗**：10 颗心血量、受击红屏、缓慢回血、死亡后在床重生点（若设置）或出生点复活
- **存档与恢复**：自动/手动/睡觉存档保存星系、各世界修改、背包、槽位耐久、光标耐久、2×2/3×3 临时格、床、容器、跃迁能量与发现记录；箱子/熔炉面板内刷新也安全。已有存档创建新/精选世界时先做可恢复备份，主菜单可反复 swap/撤销。v4/v3 自动迁移
- **程序化美术/音效**：16×16 像素纹理全部由代码生成（含工具图标与裂纹动画）；开源采样（Kenney / OpenGameArt）按 SFX、白昼 BGM、夜晚 BGM 三块延迟加载，仍支持 `file://` 离线游玩，WebAudio 程序化合成为兜底；分材质脚步声（草/沙/雪/石/木/叶…）、挖掘/放置/落地、入水溅水、水下闷音+水声、游泳气泡、羊叫、僵尸呻吟（均随距离衰减 + 立体声定位）、昼夜背景音乐交叉淡化、雨声与雷鸣
- **第一人称手持物**：右下角实时显示手持方块（立方体）或工具（精灵），挖掘/攻击/放置带挥动动画，走路轻微摆动
- **世界细节**：天空穹顶/日月星辰/云层跟随相机（地图边缘天空不再偏移）；沙子/沙砾失去支撑会下落；挖开临水的格子水会逐渐流入；生物落水会漂浮；头部浸水有蓝绿水下滤镜、闷音与近距浓雾
- **受击反馈**：被僵尸攻击有击退与挑空，屏幕边缘红色箭头指示伤害来向；死亡界面显示死因（僵尸/雷击/溺水/摔落）

## 新手流程建议

1. 砍树得橡木 → 背包 2×2 合成木板 → 2 木板合成木棍
2. 4 木板合成工作台，放置后对准按 E 打开 3×3
3. 3 木板+2 木棍合成木镐 → 长按右键开采石头与煤矿
4. 煤炭+木棍合成火把（×4），插在洞穴里照亮；8 石头合成熔炉，铁矿+煤炭烧出铁锭升级铁镐铁剑
5. 击杀羊收集羊毛，3 羊毛+3 木板合成床：夜晚睡觉跳过黑夜并记录重生点；猎猪烤猪排补充饥饿（R 进食）

## 已知限制

- 熔炉不支持烧矿石成块/食物烟熏粒子等细节；箱子无朝向（四面同贴图）
- 光照为逐格平面光照 + 顶点平滑插值；火把不支持贴墙姿态
- 单进程世界（无多人联机）
- 行星 X/Z 按区块无限流送但垂直高度仍为 64 格；默认常驻工作集与雾距有界，极高速飞行到尚未生成区块时会短暂受到加载保护
- 旧 256×256 core 初次生成约 1-2 秒 + 光照初始化约 1 秒（进度条可见）；外围区块在游玩中按小预算渐进生成
