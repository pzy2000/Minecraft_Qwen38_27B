# 星海像素重构：优先级计划与验收标准

目标：把原有单世界体素生存游戏扩展为可由一个星系种子稳定生成多颗异质星球、空间站、传送门、飞船与跃迁旅行的像素科幻探索游戏，同时保留原有采集/建造/生存玩法及桌面、移动双端能力。

## P∞ — 无限宇宙（已完成）

- [x] 宇宙种子 → 银河(g) → 恒星系(s) → 行星 四级确定性派生（universe.js）。
- [x] 起源恒星系 (0,0) 逐位复现旧版目录公式；v5 存档自动迁移、进度无损。
- [x] 每恒星系 2–6 颗行星 + 空间站；门户网络泛化至任意行星数且 ≤2 跳可达。
- [x] 星图「银河」标签页：5×5 视窗无限平移浏览邻近恒星系。
- [x] 跨系曲速跳跃：消耗曲速电池（高阶晶体×2+铁锭合成后自动装填）；抵达目标系空间站。
- [x] v6 存档：按恒星系地址隔离档案桶；只持久化有玩家痕迹的世界；LRU 裁剪。
- [x] 测试：universe_test / jump_flow_test / galaxy_ui_test 全绿；smoke 与浏览器全量回归通过。

## P0 — 数据与生成底座

- [x] 一个星系种子稳定派生 6 颗行星和 1 座空间站。
- [x] 每颗行星具有独立种子、类型、环境色、资源描述和坐标。
- [x] 行星类型会改变实际生成的群系组合，而不只是改 UI 名称。
- [x] 空间站使用独立的太空平台世界生成规则。
- [x] 存档升级为 v5；星球修改、容器元数据、落点和发现状态按世界隔离。
- [x] v4 存档可迁移为新星系的起始行星，不删除旧进度。

验收：同一种子两次得到完全相同的星系；不同种子产生不同星系；跨星球往返后各自方块修改不串档。

## P1 — 星际旅行可玩闭环

- [x] 每颗星球按种子放置多个可见、会旋转发光的传送门。
- [x] 传送门目的地覆盖其他行星和空间站，进入门体后免费旅行。
- [x] 行星降落点附近生成一艘可交互像素飞船。
- [x] 飞船提供星图；空间站可直接使用航行终端。
- [x] 跃迁引擎拥有能量、距离成本和不足拦截；抵达空间站自动补满。
- [x] 星图展示行星类型、距离、跃迁成本、发现状态及当前世界。
- [x] 旅行包含离场、跃迁过场、目标世界生成和抵达反馈。

验收：玩家可以从起始行星经传送门或飞船抵达另一颗行星/空间站，再返回；背包、生命、饥饿与行星独立进度保持。

## P2 — 像素科幻表现与双端适配

- [x] 主菜单、加载页、HUD、按钮和面板统一为深空像素终端风格。
- [x] HUD 常驻显示当前天体、类型、星系坐标和跃迁能量。
- [x] 不同行星拥有差异化天空/雾色，空间站使用深空环境。
- [x] 桌面端支持 `H` 打开星图、`E` 登舰；保留全部原键鼠操作。
- [x] 移动端提供安全区适配的“星图”按钮，星图卡片可触控操作。
- [x] 低高度横屏与窄屏下，星图可滚动且主要按钮保持可点击。

验收：桌面与强制触控浏览器测试通过；360px 级窄屏和低高度横屏无关键控件溢出。
